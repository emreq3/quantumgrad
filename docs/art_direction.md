# Art direction, visual design system and intro

**Goal.** A premium, original retro-futuristic coastal-city identity — tropical sunsets, 1980s synthwave neon, palm silhouettes, wet-street reflections, Art-Deco geometry, quantum laboratories — with the cinematic energy of a
classic crime-game opening but **no copied material**: no Rockstar or GTA logo, lettering, map, character, texture, screenshot, loading illustration, music or audio signature, and no implied affiliation (stated in Credits).
All artwork is **original, procedural SVG generated by code** (seeded random numbers + hand-written paths); all sound is synthesised at run time. No image-generation model was used and no image was downloaded.

## 1. Colour system (`frontend/src/styles.css`)

| Token | Value | Use |
|---|---|---|
| midnight | `#0B1020` | page / panels |
| deep purple | `#24133F` | gradient base, sky |
| neon pink | `#FF2D95` | primary action, logo, danger-adjacent accents |
| electric purple | `#8B5CF6` | selection, tabs, strokes |
| cyan | `#00E5FF` | scientific telemetry, sentinels, focus ring |
| sunset orange | `#FF8A45` | objectives, warnings, sun |
| warm peach | `#FFC3A0` | headings, beaches |
| soft text | `#F1F5F9` | body text (≈ 16 : 1 on midnight) |
| success `#3DE0A5`, warning `#FFC857`, failure `#FF6B8B`, locked `#8A91B8`, selected `#00E5FF`, inactive `#8A91B8`, uncertainty `#C9B1FF` | semantic |

Scientific states are never colour-only: success/failure use ✔/✘ icons and text, uncertainty uses a hatched/dotted pattern and the word "uncertain" in labels, locked content uses a lock icon and "needs X", defect states use "!" / "✓" glyphs,
X vs Z stabilizers differ by hatch pattern and letter.

## 2. Typography (bundled, SIL OFL 1.1, no external font service)

Orbitron (display: logo wordmark labels, result banners) · Rajdhani (headings, buttons) · Inter (body) · JetBrains Mono (telemetry). Installed from npm (`@fontsource/*`), latin subsets, hashed into the build; system fallbacks are in every font stack, so the game
works if a font fails. The **QTA6 wordmark is not lettering from any font**: its four glyphs (Q as a chamfered octagon with tail, T, A, a squared 6) are drawn as stroked paths with a cyan offset echo and sunset-stripe slits masked into the lower half.

## 3. Scenes

* **Menu / title / completion backdrop** — `CityBackdrop`: layered skyline (far / mid / near layers of generated buildings, 15–40 % lit windows), striped sun, stars, water with sun and neon reflections, palm silhouettes; three parallax layers drift at different speeds, palms sway, windows twinkle (CSS transforms/opacity only).
* **District scenes** — `DistrictScene(id)`: Academy (warm dusk, dome, clock tower, columns), Neon Labs (cyan/violet towers, circuit-trace signage), Sunset Bay (pink/orange sun, sail boats, measurement dishes), Quantum Core (dark server towers with LED strips, lattice dots), Circuit Harbor (cranes, containers, orange/cyan lights), Nexus Central (dense downtown, central tower with beacon and rings).
* **Quantum City map** — `MapSea` + `MAP_DISTRICTS`: shoreline with beach glow and foam, bay, neon canal with two bridges, avenues with lamp posts, piers and boats, palms; each district is a focusable button with isometric-style blocks, mission markers, lock/progress state and keyboard selection; an accessible list view replaces the map below 1000 px.
* **Portraits** — six stylized SVG busts (skin, hair, glasses, jacket and backdrop colours differ).

## 4. Interface language

"Operations console" panels with neon borders; sticky HUD (district, mission, objective, resources with cosmetic bump animation — the store's wallet stays authoritative); briefings with a speaker panel; cinematic result banners (animated rise, never strobing); workspaces:
**detection** circuit console with dashed monitored regions and a playback cursor labelled *illustrative*; **mitigation** console (budget split bar, noise-amplification table, readout matrix, extrapolation chart showing measured points, exact values, the fitted model and the extrapolated estimate separately);
**decoder** lattice puzzle (real rotated lattice, Z/X plaquettes, boundaries, defect pulse, resolved ✓, undo/clear/reset, MWPM overlay only after submission); **optimization** strategy map + text table; **N1** stage rail and restoration board.

## 5. Opening sequence (`frontend/src/screens/Intro.tsx`)

| Time | Scene | Content |
|---|---|---|
| gate | choice | "Start with sound" · "Start silent" · "Skip intro" (satisfies the browser autoplay policy; sound only after a user choice) |
| 0–3 s | studio | black → hexagon emblem with three orbits drawn by stroke animation, a white particle pulses, studio label fades in (optional sting) |
| 3–6 s | Quantum City | skyline, setting sun, parallax and water reflections; "QUANTUM CITY" |
| 6–9 s | emergency | laboratory scene, "EMERGENCY BROADCAST", network status flips NOMINAL → UNSTABLE, restrained glitch (≤ 3 px, ~0.12 s per 3 s), "QUANTUM NETWORK OFFLINE", "Six districts. One failing quantum network." |
| 9–12 s | title | QTA6 wordmark with pink/purple/cyan light, subtitle QUANTUM CITY, then straight into the main menu |

Behaviour: skip button, **any key / Escape / tap / click** skips; replay from Settings; "always skip" option; plays at most once per browser session (`sessionStorage`); reduced-motion variant = four static cross-fading cards (1.6 s each, no motion);
the page behind it is `inert`; focus moves to the main content afterwards; the animation clock is a throttled `requestAnimationFrame` loop cancelled on unmount; audio context and timers are disposed; the intro is wrapped in an error boundary and is dropped if it ever throws, so it cannot prevent access to the game.
Studio label: configurable (`VITE_QTA6_STUDIO`), default "QTA6 STUDIO" — **no team or studio name was assumed**.

## 6. Audio identity (`frontend/src/audio/synth.ts`)

Web Audio only: square/triangle/saw oscillators with envelopes and low-pass filters, a four-chord pad loop in a minor-pentatonic palette with a hint of filtered noise and a six-note arpeggio, plus 11 UI/gameplay cues (select, tick, confirm, back, error, execute, success, failure, briefing, complete, studio sting). Master output is **capped at 60 %**
(sliders cannot exceed it), muted by default, persisted settings, unlocked by the first gesture. Verified in Chromium that the context runs and its clock advances (`results/e2e/audio_check.json`); **nobody has listened to it yet** — the sound design is unreviewed by a human.

## 7. Motion and comfort

CSS transforms/opacity and SVG only; nothing flashes faster than 3 Hz; Settings offers *system / reduced / full* motion (honours `prefers-reduced-motion`), large text, and the intro is optional. Animations never carry scientific information that is not also present as text or numbers.

## 8. Limitations

Procedural vector art, not hand-painted illustration; no character animation or voice; no raster textures; the city map is a stylized schematic (not geographically meaningful); sound is placeholder-grade synthesis awaiting human sound design.
